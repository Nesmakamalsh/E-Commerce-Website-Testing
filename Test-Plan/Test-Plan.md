
# Test Plan

## 1. Objective

The objective of this project is to evaluate the functionality, reliability, and usability of the SauceDemo e-commerce web application through structured manual testing.

## 2. Testing Scope

Testing will cover:
- Login and authentication
- Product inventory
- Product sorting
- Shopping cart
- Checkout information
- Order overview
- Order completion

## 3. Testing Types

- Functional Testing
- Positive Testing
- Negative Testing
- Boundary Value Testing
- Validation Testing
- Exploratory Testing
- Regression Testing

## 4. Test Approach

Test cases will be designed and managed in Jira using Zephyr Test Management. Test execution will be performed manually, and defects will be documented and tracked in Jira.

## 5. Entry Criteria

- Application is accessible.
- Testing environment is available.
- Test scenarios have been identified.
- Test data is available.

## 6. Exit Criteria

- Planned test cases have been executed.
- Execution results have been recorded.
- Identified defects have been documented.
- Final test report has been prepared.

## 7. Deliverables

- Test plan
- Test scenarios
- Test cases
- Test execution results
- Defect reports
- Final test report

## 8. Risks and Limitations

- The application is a demo environment.
- Application behaviour may be intentionally altered for certain test accounts.
- Application availability and behaviour may change over time.
