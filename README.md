# E-Commerce-Website-Testing
Manual testing of an e-commerce web application using Jira and Zephyr, covering test planning, test case design, execution, defect tracking, and reporting.

## Project Overview

This project focuses on manually testing the SauceDemo e-commerce web application to evaluate its core functionalities, user journeys, input validation, and error handling.

Test cases are managed and executed using Jira and Zephyr. Test results, identified defects, and supporting evidence are documented throughout the project.

## Application Under Test

- **Application:** SauceDemo (Swag Labs)
- **URL:** https://www.saucedemo.com/
- **Application Type:** E-commerce web application
- **Testing Type:** Manual Testing

## Tools & Technologies

- Jira
- Zephyr Test Management

## Testing Scope

The initial testing scope includes:

- Login and Authentication
- Products / Inventory
- Product Sorting
- Shopping Cart
- Checkout
- Order Overview
- Order Completion

Additional scenarios will be included based on exploratory testing.

## Testing Approach

1. Explore the application and identify its main functionalities.
2. Define the testing scope and test scenarios.
3. Design detailed test cases.
4. Organize test cases in Zephyr.
5. Create and execute test cycles.
6. Record actual results and execution statuses.
7. Identify, document, and track defects in Jira.
8. Export test cases and execution results.
9. Prepare the final test execution report.

## Test Case Management

Test cases are designed, organized, and maintained in Zephyr.

Exported test cases and their summaries will be stored in the `Test-Cases/` directory.
